# XBuddy · 个人投资研究 Agent 工作台

> 一个面向投资研究者的可交互 Web 产品：用户输入研究目标，Agent 规划任务、调用模拟金融工具、管理检查点与长期状态，并在人工批准后生成带趋势图和证据链的可验证研究结果。

## 产品要解决的问题

传统 AI 投研摘要常直接给出结论，却没有清楚交代研究边界、数据来源、工具失败、反方证据和人工责任。XBuddy 把这些环节显性化：研究结果不在任务开始时预置，而是在证据收集、异常处理和检查点复核完成后才生成。

## 核心体验

```text
输入研究目标
  → 生成可确认的五步研究计划
  → 采集原始证据并展示字段与口径
  → 处理 OTIX 工具超时：批准备用源 / 保存暂停
  → 复核来源、反方证据、成本和缺口
  → 人工批准后生成图文研究结果与证据链
```

| 能力 | Demo 中的表现 |
| --- | --- |
| 对话式研究入口 | 用户在主输入框给出研究目标，系统创建研究线程。 |
| 任务规划 | 五步计划包含范围、字段、证伪条件、预算与预期产出。 |
| 工具与产物 | 右侧“任务进程”展示待办、工具/MCP 和阶段产物，支持收起。 |
| 异常恢复 | OTIX 超时不会被跳过；系统保留失败记录，要求用户选择备用源或暂停。 |
| 检查点 | 最终总结前展示来源数、异常、成本、反方证据与待确认事项。 |
| 长期记忆 | 可打开研究方法论、可信来源偏好和待验证假设。 |
| 可验证结果 | 最终直接展示事实/推断/不确定性、Canvas 趋势图、研究展开和四条证据链。 |

## 产品选择

### 对话即工作台

研究目标、Agent 解释、工具执行、异常处理、人工批准和最终结果处于同一线程，避免用户在聊天、任务面板和报告页之间切换。

### Harness 右置且可收起

右侧面板用于透明呈现任务、工具和产物；主区保持研究阅读优先。它体现 Agent Harness 的运行机制，但不让技术监控淹没结果阅读。

### 结果后置生成

计划、采集、异常和检查点阶段仅展示过程、原始证据和缺口。最终结论、趋势图与证据链仅在用户批准生成研究报告后出现。

### 研究而非荐股

所有最终内容区分“已验证事实”“研究推断”“尚不确定”。Demo 不提供买卖建议、收益承诺、目标价或确定性价格预测。

## Agent Harness 映射

| 运行机制 | 当前 Demo | 真实版本建议 |
| --- | --- | --- |
| 规划器 | 将目标拆为五步计划和证伪条件。 | 支持目标澄清、依赖关系与多计划比较。 |
| 工具注册表 | 展示行情、公告解析、产业数据检索。 | 接入 OAuth、最小权限、限流与健康检查。 |
| 执行器 | 按按钮推进采集、验证和恢复状态。 | 异步队列、并发、重试、成本与 Trace。 |
| 上下文与检查点 | 展示任务、预算、已归档证据、暂停恢复。 | 版本化线程、压缩摘要和跨会话检索。 |
| 长期记忆 | 展示方法论、来源偏好、待验证假设。 | 用户确认写入、过期策略和权限隔离。 |
| 人工审批 | 备用源和最终结果生成前需确认。 | 角色权限、通知和审计记录。 |

## 技术实现

- React 19 + Vite 6 单页应用；
- `@phosphor-icons/react` 提供界面图标；
- React 本地状态模拟 `welcome → plan → collecting → recovery → checkpoint → memo`；
- Canvas 绘制模拟库存趋势图；
- Node test runner 校验静态资源、SPA 回退、API 请求边界和部署包结构；
- GitHub Actions 在 `main` 推送后自动构建并发布 GitHub Pages。

## 环境变量与数据来源

当前 Demo **没有环境变量、没有 API Key、没有真实外部请求**。页面中的公司披露、WSTS、渠道数据和终端需求均是模拟来源类型；数值、时间、费用和异常日志均只服务于产品演示。

正式版本应将数据供应商密钥、模型密钥、来源白名单、审计存储和权限策略配置在服务端环境变量中，严禁提交到前端仓库。

## AI 的角色

AI 协助完成产品方案、视觉探索、React 代码、交互状态、构建测试和文档整理。人工持续审阅并纠正 AI 的不合理输出，包括结果过早展示、缺少交互、视觉过度模仿外部产品、最终内容过少和关键控件不可用。详见 [AI_USAGE.md](AI_USAGE.md)。

## 已知边界与未做事项

- 数据、来源、成本和工具调用为模拟状态，刷新后不持久化；
- 未接入真实金融数据、模型 API、用户账户、协作、后台队列、真实权限或审计存储；
- 不构成证券研究报告、投资建议或收益承诺；
- 当前开发环境的内置浏览器无法完成截图级视觉 QA，`design-qa.md` 如实标记为 `blocked`；
- 应在公开 URL 上完成跨浏览器、移动端、无障碍和真实数据接入后的回归测试。
