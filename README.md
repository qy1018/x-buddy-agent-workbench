# XBuddy · 个人投资研究 Agent 工作台

一个面向投资研究者的可交互 Web Demo。它把“提出研究问题 → 规划任务 → 核验证据 → 用户审批 → 形成研究备忘录”呈现在同一条工作流中，重点是可验证研究，而非自动化荐股。

## 体验主链路

1. 点击“新建研究”，输入一个研究目标。
2. 在中心画布阅读事实、推断与不确定性；点击证据链卡片，右侧会切换到对应的来源、时点与口径。
3. 点击“查看 Agent 运行记录”，查看计划、工具执行、检查点、成本和一次已恢复的数据失败。
4. 点击“审阅并批准下一阶段”，在检查点确认后生成研究备忘录状态。

## 产品选择

- **研究阅读优先**：中心区域只呈现研究问题、当前判断、趋势和证据链；运行机制不与核心阅读争夺注意力。
- **Harness 可见但按需展开**：任务执行、接口失败、备用源与恢复记录收进运行抽屉与检查点。
- **可追溯结论**：每项证据都有来源、获取时间、新鲜度、原始摘录与方法说明；结论被明确分为事实、研究推断和不确定性。
- **合规边界**：Demo 不提供买卖建议、价格预测或收益承诺。模拟数据均为产品演示用途。

## 运行

```bash
npm install
npm run dev
```

生产构建与部署包校验：

```bash
npm run build
npm run test:sites
```

## 技术与数据边界

- React + Vite 单页 Demo。
- 采用预置的构造研究数据，不会发起真实金融数据请求，也没有 API Key。
- 产品结构为接入扶摇/iFinD 等工具预留了清晰位置；正式版本应将能力注册、数据权限、速率限制、工具调用审计和证据归档接到后端。
- 长期记忆、检查点和恢复在 Demo 中以可见产品状态演示；正式版本应持久化为版本化线程状态与审计日志。

## 已知事项

- 运行记录、研究计划和数据源均为交互式模拟；不替代真实的模型、金融数据服务或人工投研判断。
- 当前工作环境的内置浏览器无法访问本地预览，因此 `design-qa.md` 如实标记为 `blocked`，需要在可访问本地服务的浏览器中完成最终截图比对。
